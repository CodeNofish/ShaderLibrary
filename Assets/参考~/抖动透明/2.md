| `DitherCommon.hlsl` | 内部静态算法，不导出 | Bayer 递归阈值、量化、clip 判定、两类时序偏移 |

关键设计：
- 所有抖动函数统一返回 `alpha - threshold`（clip 值，`> 0` 保留、`<= 0` 丢弃），直接接 ShaderGraph 的 Alpha Clip Threshold 或 `clip()`，从而走不透明渲染路径；`DitherKeepMask` 可转成 0/1 供后处理使用。
- Bayer 阈值用 `M2 = [[0,2],[3,1]]` 解析式递归构造 4×4/8×8，零常量数组、零纹理带宽、纯 ALU。
- 注释中写明文档约束：TAA/TSR 协同需要 Dither 材质在 TAA Pass 之前渲染并写入深度/速度缓冲；Shadow Caster Pass 必须用相同 `dither`/`screenPos`/`size` 同步裁剪；未开时序抗锯齿会退回粗糙点阵、可能产生 Ghosting。
- Floyd–Steinberg 严格实现依赖像素间顺序数据依赖，实时 GPU 需 Compute Shader 多 Pass（文档也未提供并行化案例），因此只提供四邻域误差补偿的并行近似并明确标注，实时主流仍推荐 Bayer / Blue Noise。

校验：脚本核对 17 个导出函数的 `paramhints` 与签名参数名、`ProviderKey`、必需注解标签全部一致，整个 Library 无重复 ProviderKey/GUID，6 个特性文件均引用 `DitherCommon.hlsl`，IDE 诊断为空；临时脚本已清理。未在 Unity 编辑器内实际编译预览，需绑定 Custom Function Node 后验证。
