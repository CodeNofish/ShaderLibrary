Glitch（故障艺术）与 Chromatic Aberration（色差）在 Shader 后处理中属于两个独立但常组合使用的效果体系。依据检索到的技术资料，其具体分类如下：

### 一、 Glitch Shader 效果的具体分类
Glitch Art 的核心在于通过 UV 坐标变换、通道分离和噪声引入来模拟数字信号损坏。根据腾讯互娱工程师毛星云及多项 Shader 技术文档的总结，主流 Glitch 后处理特效可分为以下十类：

1.  **RGB 颜色分离故障 (RGB Split / Color Shift Glitch)**
    *   **原理**：对 R、G、B 三个通道分别使用不同的 UV 偏移量进行采样并重组。
    *   **表现**：图像边缘出现红/青或绿/紫的色彩错位重影，是故障艺术最基础且标志性的效果。
2.  **错位图块故障 (Image Block Glitch)**
    *   **原理**：将屏幕分割为若干矩形块（Block），利用噪声纹理对特定图块施加随机位移或替换为纯色/上一帧缓存。
    *   **表现**：模拟视频编码错误或显存损坏导致的局部马赛克、色块丢失。
3.  **错位线条故障 (Line Block Glitch)**
    *   **原理**：以水平或垂直线条为单位进行块状错位，通常结合阈值控制触发概率。
    *   **表现**：类似数据传输丢包产生的横向或纵向条纹撕裂。
4.  **图块抖动故障 (Tile Jitter Glitch)**
    *   **原理**：对网格化的小图块施加高频随机位移。
    *   **表现**：画面呈现细碎的颗粒状抖动，模拟信号接触不良。
5.  **扫描线抖动故障 (Scan Line Jitter Glitch)**
    *   **原理**：基于扫描线位置生成随机偏移量，仅对部分扫描线应用水平位移。
    *   **表现**：模拟老式 CRT 显示器或 VHS 磁带信号干扰时的水平线条错位。
6.  **数字条纹故障 (Digital Stripe Glitch)**
    *   **原理**：在特定区域覆盖高对比度的二进制风格条纹图案。
    *   **表现**：增强赛博朋克风格的数字化装饰感。
7.  **模拟噪点故障 (Analog Noise Glitch)**
    *   **原理**：叠加基于时间的伪随机噪声纹理。
    *   **表现**：模拟模拟信号传输中的雪花点和静电干扰。
8.  **屏幕跳跃故障 (Screen Jump / Vertical Jump Glitch)**
    *   **原理**：对整体画面的 V 轴（垂直方向）施加瞬时的全局偏移或插值跳动。
    *   **表现**：模拟垂直同步失败导致的画面上下翻滚或瞬移。
9.  **屏幕抖动故障 (Screen Shake Glitch)**
    *   **原理**：对整体画面施加随机的 XY 轴平移。
    *   **表现**：模拟强烈的信号冲击或设备震动。
10. **波动抖动故障 (Wave Jitter Glitch)**
    *   **原理**：使用正弦波等函数对 UV 坐标进行非线性扭曲，通常随时间动画化。
    *   **表现**：画面呈现液态或磁带式的不稳定波浪形变。

> **注**：在实际 Shader 实现中，上述效果常被组合使用（如 RGB Split + Scan Line Jitter + Screen Shake），并通过噪声函数（Hash/Random）和时间参数控制触发强度与节奏。

### 二、 Chromatic Aberration (色差) Shader 效果的分类
在光学物理和 Shader 模拟中，色差严格分为两类，二者成因与视觉表现不同：

| 分类 | 英文名称 | 别称 | 成因与表现 | Shader 模拟方式 |
| :--- | :--- | :--- | :--- | :--- |
| **轴向色差** | Longitudinal / Axial CA | 纵向色差、位置色差 | 不同波长光线沿**光轴方向**聚焦位置不同。导致图像整体或焦平面前后出现彩色光晕（如焦前紫边、焦后绿边），画面中心亦可见。 | 模拟较复杂，通常需结合深度信息或模糊半径随波长变化来实现；简单后处理较少单独模拟此项。 |
| **倍率色差** | Lateral / Transverse CA | 横向色差、垂轴色差 | 不同波长光线的**放大率**不同，导致在同一焦平面上成像大小不一。仅在画面边缘/角落明显，呈对称色边（如内侧绿/外侧紫）。 | **Shader 中最常见的色差效果**。通过对 R/G/B 通道施加径向或单向的 UV 缩放/偏移差值来模拟。 |

#### 补充说明
*   **Shader 中的“色差”通常指横向色差**：绝大多数游戏引擎和后处理库（如 Unity Post-processing Stack, Unreal Engine）中的 Chromatic Aberration 节点，本质上是通过偏移 RGB 通道 UV 来模拟 **Lateral CA**，这与 Glitch 中的 RGB Split 算法高度相似，区别仅在于色差通常是径向对称且连续的，而 Glitch 的 RGB Split 往往是随机、离散或单向的。
*   **初级与次级光谱**：在精密光学设计中还区分初级光谱（红蓝焦点差异）和次级光谱（消色差后残留的绿光焦点差异），但在实时渲染 Shader 中一般不作此细分，统一通过通道偏移参数控制强度。

### 三、 两者的关系
*   **包含关系**：RGB Split 既是 Glitch 的核心子类，也是模拟横向色差的底层算法。
*   **应用区分**：当 RGB 通道偏移用于模拟镜头光学缺陷、追求径向对称和边缘渐变时，归类为 **Chromatic Aberration**；当偏移用于表达信号故障、伴随随机抖动、块状撕裂或非线性扭曲时，归类为 **Glitch Effect**。
