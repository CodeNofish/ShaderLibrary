依据检索到的 Unity URP、Unreal Engine 官方文档及多项 Shader 后处理技术资料，Color Grading（色彩分级）与 Tone Mapping（色调映射）在实时渲染管线中属于两个独立但紧密关联的模块。结合胶片颗粒与暗角效果，其具体分类如下：

### 一、 Tone Mapping（色调映射）的具体分类
Tone Mapping 的核心功能是将 HDR（高动态范围）光照数据非线性压缩至 SDR（标准动态范围）显示设备的  区间，避免高光截断或暗部细节丢失。根据算法原理与视觉特征，主要分为以下四类：

| 分类 | 代表算法/模式 | 视觉特征 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **电影级映射** | ACES (Academy Color Encoding System) | 高对比度，高光压缩柔和自然，会改变色相与饱和度以模拟胶片响应。Unity 中启用此模式时，后续调色操作会自动切换至 ACES 色彩空间以保证精度。 | 追求影视化质感、高反差场景、3A 游戏默认选项。 |
| **中性映射** | Neutral | 仅做动态范围重映射，对色相和饱和度的影响最小，过渡平缓自然。 | 需要保留原始色彩关系以便后续进行大幅度 Color Grading 的场景；开放世界自然光照。 |
| **经典全局映射** | Reinhard | 公式简单（$L_{out} = L_{in}/(1+L_{in})$），能保留高光细节，但局部对比度不足，画面易显灰暗。性能消耗最低。 | 早期渲染管线、移动端低配设备、对性能极度敏感的项目。 |
| **自定义曲线映射** | Custom Curve / Custom | 允许美术师手动调节 Toe（暗部过渡）、Shoulder（高光压缩斜率）、Gamma 等参数，完全可控。 | 风格化渲染、特殊艺术需求、ACES/Neutral 无法满足特定调性时。 |

> **注**：Unreal Engine 还提供 **Local Exposure（局部曝光）** 作为补充，它利用边缘感知数据结构对高对比度场景（如室内看窗外）进行局部亮度适配，同时保留细节，不属于传统 Tone Mapping 算子，但在管线中常与其配合使用。

### 二、 Color Grading（色彩分级/校正）的具体分类
Color Grading 是在 Tone Mapping 之后（或与之协同）对画面色彩、亮度、对比度进行艺术化调整的过程。依据实现方式与作用域，可分为以下三类：

1.  **基于 LUT（Look-Up Table）的调色**
    *   **原理**：通过 3D 纹理（通常为 32³ 或 64³）将输入 RGB 映射为输出 RGB，一次采样即可完成复杂的非线性色彩变换。
    *   **细分**：
        *   **Internal LUT**：引擎内部根据 Color Grading 面板参数（色温、色调、饱和度、RGB 曲线等）实时生成 3D LUT，兼顾灵活性与性能。Unity URP 的 High Definition Range 模式即采用 LogC 编码的 3D LUT 存储 HDR 调色结果。
        *   **External LUT**：导入外部软件（DaVinci Resolve、Photoshop 等）制作的 .cube 文件，用于精确复现特定胶片风格或电影调色方案。NativeEnhancer-FE 等项目即通过 263 个专用 LUT 实现电影模拟。
        *   **Low Definition Range LUT**：针对低端平台，在  SDR 范围内应用标准 LUT，不支持 HDR 调色。
    *   **优势**：将复杂的多步调色运算压缩为单次纹理采样，性能开销远低于逐像素多通道计算。

2.  **程序化参数调色（Procedural / Parametric）**
    *   **原理**：直接在 Shader 中通过数学函数调整色彩属性，不依赖 LUT 纹理。
    *   **常见控制维度**：
        *   **全局/分区调整**：阴影（Shadows）、中间调（Midtones）、高光（Highlights）的色彩平衡、饱和度、对比度独立控制。
        *   **色温/色调**：模拟白平衡偏移（Kelvin/Tint）。
        *   **RGB/HSL 曲线**：非线性调整特定色阶或色相范围。
        *   **通道混合器（Channel Mixer）**：模拟胶片感光层串扰或创意色彩偏移。
    *   **定位**：通常作为 LUT 的前置步骤或轻量级替代方案；Unity URP 的 Low Definition Range 模式即直接使用此类参数。

3.  **色彩空间感知调色**
    *   **原理**：调色操作在特定色彩空间（如 ACEScg、ACEScc、LogC）中进行，而非线性 sRGB 空间，以确保高光压缩、色彩插值和饱和度调整的物理正确性。
    *   **意义**：避免在 sRGB 空间直接调色导致的色相偏移和高光断层，是现代 HDR 管线的标配。

### 三、 Film Grain（胶片颗粒）的分类
胶片颗粒不同于数码噪点，它是银盐晶体随机分布的物理特性模拟。依据 Shader 实现方式分为：

| 分类 | 实现方式 | 特点 |
| :--- | :--- | :--- |
| **单色高斯颗粒** | 生成单色（Monochrome）高斯分布噪声，叠加于画面。 | 最基础实现，避免彩色噪点的"数码脏感"；人像建议强度 6%-10%。 |
| **通道分离颗粒** | 对 R/G/B 三通道分别施加不同强度/大小的颗粒（蓝层最锐利、红层最柔和、绿层噪点最多）。 | 精确模拟真实胶片三层感光乳剂的特性，需并行节点处理，成本较高。 |
| **色彩校准颗粒** | 颗粒颜色随场景主色调动态匹配（如森林场景颗粒偏绿）。 | 解决颗粒与 Color Grading 叠加时的偏色问题，使颗粒融入画面而非独立干扰。 |
| **分辨率自适应颗粒** | 根据输出分辨率动态调整颗粒大小与强度（如 2K: 0.15/0.15, 1080P: 0.2/0.2, 720P: 关闭）。 | 防止低分辨率下颗粒过于粗糙破坏画质。 |

> **关键区分**：资料明确指出"胶片风格不仅仅在于色彩"，LUT 只能完成色彩转换，真正的胶片感必须包含颗粒、通道差异和光学缺陷的组合模拟。

### 四、 Vignette（暗角/晕影）的分类
依据生成方式与用途，Shader 中的暗角效果分为两类：

1.  **程序化暗角（Procedural Vignette）**
    *   **原理**：实时计算像素到屏幕中心的欧氏距离，通过 `pow(saturate(1 - dist²), smoothness)` 等衰减函数生成径向渐变遮罩。
    *   **参数**：Intensity（强度）、Smoothness（过渡平滑度）、Roundness（圆度）、Center（中心偏移）。
    *   **性能**：约 0.3ms @1080p，适合常规聚焦引导。
    *   **执行顺序注意**：应在 Bloom **之前** 执行，先暗化边缘再进行泛光计算，避免 Bloom 光晕在边缘被截断产生断层。

2.  **蒙版暗角（Masked Vignette）**
    *   **原理**：采样外部纹理作为遮罩，支持任意形状（星形、不规则边框等）。
    *   **用途**：艺术化效果、复古取景器模拟、UI 聚焦等特殊需求。
    *   **代价**：增加一次纹理采样与内存带宽消耗。

### 五、 后处理管线中的执行顺序
依据 URP 优化实践，上述效果的推荐执行顺序遵循"从基础调整到风格强化"原则：

1.  **Color Grading**（奠定整体色调基础）
2.  **Vignette**（引导视线聚焦，需在 Bloom 前）
3.  **Depth of Field**（突出主体）
4.  **Bloom**（强化高光区域）
5.  **Motion Blur**（按需，平滑动态画面）
6.  **Film Grain**（最后叠加，提升艺术质感）

此顺序确保了各效果之间的视觉一致性，避免了常见的叠加异常（如暗角截断泛光、颗粒与调色偏色等）。
