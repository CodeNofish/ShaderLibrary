依据检索到的 Unity HDRP 官方文档、Unreal Engine 社区技术资料及多项 Shader 实现教程，Underwater（水下效果）与 Caustics（焦散）在实时渲染中属于两个独立但高度协同的模块。以下是其算法与分类的详细介绍：

### 一、 Underwater Distortion（水下扭曲）算法分类
水下扭曲的核心是模拟光线穿过波动水面时的折射偏移。根据驱动源和实现方式，主要分为以下三类：

1.  **噪声/法线贴图驱动扭曲 (Noise / Normal Map Driven)**
    *   **原理**：利用两张或多张法线/噪声纹理沿不同方向滚动采样，将得到的法线值作为 UV 偏移量对屏幕空间纹理（GrabPass 或 Scene Color）进行重采样。
    *   **细分算法**：
        *   **双向滚动混合**：两个 UV 扭曲方向相差约 90°，简单有效，适合模拟水下各向同性扰动。
        *   **Flow Map 驱动**：使用流动贴图精细化控制局部扭曲方向、速度和明暗变化，消除纯噪声的机械重复感。
        *   **时间错位平滑**：通过 `frac(time)` 和 `frac(time + offset)` 获取两组扭曲结果并混合，消除循环接缝处的视觉跳变。
    *   **特点**：性能开销低，美术可控性强；但物理准确性较弱，不随水深自动衰减。

2.  **深度感知扭曲 (Depth-Aware Distortion)**
    *   **原理**：读取场景深度缓冲（Depth Texture），计算当前像素的水体厚度（Water Depth = Water Surface Z - Scene Z），将深度差作为扭曲强度的遮罩或缩放因子。
    *   **关键实现**：
        *   **Reverse-Z 适配**：在 Godot 4.3+ 等使用反向 Z 缓冲的引擎中，需将比较逻辑从 `step(water_depth, scene_depth)` 改为 `step(scene_depth, water_depth)`，否则会导致水面前方物体被错误扭曲。
        *   **归一化深度差**：将实际深度差除以 `MaxWaterDepthDiff` 参数，用于统一控制浅水/深水过渡、焦散范围和泡沫显示。
    *   **特点**：物理表现更真实（近处扭曲弱、深处扭曲强），避免水面前方物体穿帮。

3.  **顶点位移扭曲 (Vertex Displacement)**
    *   **原理**：直接在顶点着色器中对水面 Mesh 施加 Gerstner 波或正弦波位移，配合折射率计算真实的光线偏折方向。
    *   **特点**：几何级真实度最高，可正确模拟波浪轮廓对折射的影响；但性能消耗大，通常仅用于近景水面或高质量过场。

### 二、 Caustics（焦散）算法分类
焦散是光线经水面折射后在水底汇聚形成的光斑图案。依据生成机制，分为四大类：

| 分类 | 核心算法 | 原理与特点 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **程序化噪声焦散** | Voronoi / RotateMin / TriTwist | 通过数学函数实时生成焦散图案：• **Voronoi**：生成细胞状光斑，用 `pow` 增强对比度；• **RotateMin**：矩阵变换+分形最小值合并，形成网状光纹；• **TriTwist**：三角形扭曲算法，产生锐利几何光斑。 | 移动端、风格化水体、无需精确物理的场景。零纹理带宽，纯 ALU 计算。 |
| **预烘焙贴图投影** | Caustics Texture Overlay | 采样预制的焦散贴图，以世界坐标 XZ 平面投影到水底表面，避免焦散"漂浮"在水面。可结合深度遮罩限定作用区域。 | 中低端平台、静态水域。性能极低但缺乏动态变化。 |
| **波动模拟焦散** | Wave Simulation Band (HDRP) | 基于水体波动模拟数据（Ripples / Swell Band）实时计算光线汇聚强度。HDRP 的 `EvaluateSimulationCaustics` 节点输出单通道灰度焦散图，支持切换不同频段（涟漪 vs 涌浪）。 | 高端 PC/主机、开放世界海洋/湖泊。物理一致性好，可与水面动画联动。 |
| **光子映射 / 光线追踪焦散** | Photon Mapping / RT Caustics | • **分布式光子映射**：追踪光子路径并存储于光子图中，支持交互更新，可达 22 FPS；• **LHPC (Light Half Path Caustics)**：从光源方向追踪局部光路+降噪器，结合 IRTT 处理透明体粗糙度；• **光谱色散加速**：波长聚类+自适应光子尺寸，7 色采样近似连续光谱。 | 影视级实时渲染、玻璃/宝石焦散、需要色散效果的场景。硬件要求高。 |

#### 焦散的区域限定（Mask）机制
检索材料确认了多种将焦散限定在特定区域的实现方式：

*   **深度遮罩 (Depth Mask)**：利用水体深度差作为乘数，使焦散仅在浅水区可见，深水区自然衰减消失。
*   **Z-Height Mask (UE Light Function)**：在 Unreal Engine 中通过 Light Function 读取世界 Z 坐标，仅在水面以下的几何体上投射焦散，水面以上部分自动剔除。
*   **Decal Projector 扩展 (HDRP)**：默认焦散仅影响水下表面；若需投射到水上物体（如船体吃水线附近），可通过脚本调用 `GetCausticsBuffer()` API 获取焦散纹理，注入 Decal Projector 实现自定义区域投射。
*   **亮度阈值遮罩 (Post-Process)**：在后处理阶段读取场景亮度，仅对已有一定亮度的像素叠加焦散，间接排除阴影区域（但可能误检高亮纹理）。

### 三、 水下扭曲与焦散的协同注意事项
*   **色彩一致性**：程序化生成的焦散（如 Voronoi）直接与扭曲后的画面相加可能导致色调不协调。建议对焦散输出应用 HDR 颜色着色，并与水体折射色（RefrColor）匹配。
*   **执行顺序**：水下扭曲通常在透明队列或后处理中执行，焦散则作为光照贡献叠加。若使用后处理方案，应先完成扭曲再叠加焦散，避免焦散图案本身被扭曲导致失真。
*   **单通道优化**：HDRP 的焦散节点仅输出红色通道（灰度强度），使用时必须分离 R 通道再参与光照计算，直接连接 Base Color 会导致画面偏红。这是有意为之的性能优化设计。
