| 文件 | 函数 | 对应文档分类 |
| :--- | :--- | :--- |
| `OcclusionDetection.hlsl` | `ZTestGreaterOcclusion`、`StencilOcclusion`、`DepthTextureOcclusion` | 遮挡判定：Multi-Pass ZTest Greater、Stencil NotEqual 排除自身可见像素、`_CameraDepthTexture` 单 Pass 比较（均含 Reverse-Z 与 bias/softness） |
| `EdgeDetection.hlsl` | `SobelMaskEdge`、`LaplacianMaskEdge`、`DepthEdge`、`NormalEdge`、`CombineEdges` | 后处理边缘检测 + 目标掩码：Sobel/Laplacian 卷积、深度与法线差分、多源轮廓组合 |
| `SilhouetteFill.hlsl` | `FresnelRim`、`GhostFill`、`OutlineVertexOffset`、`StructuralXRay`、`AnimatedPulse`、`SilhouetteNoise` | 视觉表现：Fresnel 幽灵填充、顶点膨胀描边、结构化透视、sin/噪声脉冲 |
| `XRayComposite.hlsl` | `OccludedEdge`、`OcclusionAlpha`、`XRayComposite` | 幽灵轮廓 × 遮挡遮罩、透明度合成、最终叠加输出 |
| `SilhouetteCommon.hlsl` | 内部静态算法，不导出 | 深度遮挡判定（Reverse-Z）、脉冲、Hash |

需要特别注意：文档中的四类遮挡判定有三类本质是 **Pass / RenderFeature 状态配置**，函数库只能实现其中的深度比较与遮罩逻辑。相关配置已写入各文件注释：X-Ray Pass 需在 Opaque 之后、Transparent 之前（`Queue=Geometry+1`）、`ZTest Greater + ZWrite Off` 配 `ZTest LEqual` Normal Pass、Stencil 写入 `Ref=254` + `Comp NotEqual`、`Cull Front` 顶点膨胀、开启 Depth Texture 与目标掩码 RT、URP 不使用 GrabPass 及 SRP Batcher 兼容性。文档未涵盖的 RT Visibility Buffer 也注明不在实现范围，并说明批量目标 / 少量目标的性能取舍。
