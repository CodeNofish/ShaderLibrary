# ShaderLibrary

A lightweight, modular shader library built for Unity’s Universal Render Pipeline. It provides ready-to-use materials and reusable HLSL utilities for common 3D workflows, keeping performance, readability, and project integration in mind.

## Usage

### Installation

Install from git url.

```text
"fishwork.shader-library": "https://github.com/CodeNofish/ShaderLibrary.git?path=/Assets/Packages/ShaderLibrary",
```
