**SDF（有符号距离场）的核心价值在于：用“空间点到最近表面的带符号距离”统一表示几何，天然支持高效查询、平滑插值、布尔/混合运算、梯度求法线，以及光线步进（Ray Marching / Sphere Tracing）。**

### 基础定义
对空间中任意点 $x$，SDF 返回到最近表面的最短距离：
- **正值**：点在物体外部；
- **负值**：点在物体内部；
- **零值**：点恰好在表面上；
- **梯度** $\nabla \text{SDF}(x)$：近似表面法线方向。

### 相关算法
| 类别 | 算法/方法 | 作用 |
|---|---|---|
| 渲染 | Ray Marching / Sphere Tracing | 沿视线按 SDF 距离步进求交 |
| 法线 | 中心差分梯度 | 从 SDF 数值求导得到表面法线 |
| 阴影 | 距离场软阴影 | 沿光照方向步进，累积遮挡估计半影 |
| 重建 | Marching Cubes / Dual Contouring | 从 SDF 零等值面提取三角网格 |
| 融合 | TSDF | 截断 SDF，用于多视角深度/点云融合 |
| 生成 | Jump Flooding Algorithm | 从二值图高效生成 2D 距离场 |
| 生成 | Mesh-to-SDF / Compute Shader | 从网格实时烘焙或计算 3D SDF |
| 学习 | DeepSDF / Neural SDF | 用 MLP、特征网格或三平面学习连续 SDF |
| 学习 | Eikonal 约束 | 通过 $\|\nabla \phi\|=1$ 让网络输出更接近真实 SDF |
| 学习 | G2SDF / 3DGS+SDF | 将高斯表示与隐式 SDF 结合提升表面质量 |
| 学习 | Kernel-SDF / PSDF | 用核回归或概率模型估计带不确定性的 SDF |
| 几何 | 布尔运算 / 平滑混合 | union、intersection、difference、smooth blend |
| 几何 | 域操作 | twist、bend、repeat、mirror、domain warping |



### 主要应用领域
- **实时渲染与游戏引擎**：UE5 的 Mesh Distance Fields 用于 Lumen 全局光照、距离场环境光遮蔽 DFAO、距离场软阴影和 GPU 粒子碰撞；Unity 中可用于实时阴影、DFAO、角色毛发碰撞、体积烟雾、消融效果、后处理特效等。
- **程序化几何与材质**：在 Shader 中用 SDF 原语组合 UI、遮罩、转场、VFX 和复杂有机形状，分辨率独立且适合 GPU 并行。
- **字体与 UI 抗锯齿**：SDF 字体是经典应用，可让文字在任意缩放下保持平滑边缘；也可扩展到几何抗锯齿。
- **三维重建**：从多视图、深度图、点云或 RGB-D 序列恢复连续表面，常用 TSDF 融合、Neural SDF、稀疏点云 SDF 推断等方法。
- **NeRF / 3DGS 几何增强**：纯 NeRF 或 3DGS 擅长外观合成，但表面提取不稳定；引入 SDF 约束后可获得更水密、更稳定的网格。
- **机器人与运动规划**：SDF 可直接用于碰撞检测、避障、轨迹优化、操作规划；还有配置空间距离场 CDF，把“距离到障碍”推广到关节空间。
- **物理仿真与接触检测**：用于刚体、超椭圆体、可变形体的接触判断、穿透深度估计和法线方向计算。
- **SLAM 与地图表示**：TSDF/Neural TSDF 可用于稠密建图、主动感知、不确定性预测和轨迹规划。
- **医学成像与体绘制**：SDF/TSDF 可用于从 CT/MRI 等体积数据中提取等值面，或作为几何先验约束重建。

### 工程取舍
SDF 的优势是**分辨率独立、可微、适合 GPU 并行、易于做布尔/混合/变形**；主要瓶颈是**内存与生成成本**。高分辨率 3D SDF 通常需要稀疏体素、层次化 SDF、压缩、局部/全局双层结构，或用 Neural SDF、三平面、哈希网格等隐式表示替代。
