“ColorLuma”不是一个标准颜色空间名，通常是指 Luma / Luminance，也就是颜色的亮度分量；和它并列的常见属性是 Chroma 色度、Hue 色相、Saturation 饱和度、Lightness/Value 明度、Contrast 对比度。

和 Luma 最接近的一组属性
属性   常见缩写   含义
Luma   Y'   伽玛编码后的亮度信号，视频里常用，如 Y'CbCr

Luminance   Y   物理/感知亮度，反映人眼看到的明暗程度

Chroma   C   颜色的鲜艳/强度，不依赖明暗

Hue   H   颜色种类，如红、绿、蓝

Saturation   S   饱和度，颜色有多“纯”或多“灰”

Lightness / Value   L / V   明度或亮度层级，越接近 1 越亮

Contrast   —   明暗差异程度，不是独立颜色通道，但常和 Luma 一起调

在 Shader / Unity 里怎么用

Luma / Luminance：常用来把颜色转成灰度，或者作为遮罩、边缘检测、后处理权重。Unity 里常用类似  
dot(color, float3(0.2126, 0.7152, 0.0722)) 计算亮度。
Hue / Saturation / Value：适合做整体调色、故障效果、受击变色、氛围切换。Unity Shader Graph 里有 Hue、Saturation、Contrast 节点。
Chroma / Luma 分离：适合做“只改亮度不改颜色”或“只增强饱和度不影响明暗”的效果。
高级感知空间：如 CIELAB / LCH，L 是明度，C 是色度，H 是色相，感知更均匀，但 HLSL 里需要自己写 RGB → XYZ → LAB → LCH 转换。

简单记忆：  
Luma/Luminance 管明暗，Hue 管是什么颜色，Saturation/Chroma 管有多鲜艳，Contrast 管明暗拉开多少。  
如果你是在 Unity Shader Graph 里找对应节点，先用 Saturation、Hue、Contrast；需要纯亮度时，用 dot 计算 Luma 或写一个 Custom Function 输出 Luma。
